# Java Silver 17 Trainer

面向 Java Silver 17 的原创模拟训练 Android App。目标不是背真题，而是用大量原创变体题覆盖知识点，让使用者靠理解做对。

## 功能

- 840 道原创模拟题，不包含真实考试原题。
- 7 个大纲阶段：基础声明、类型与字符串、流程控制、数组集合、方法构造器、继承多态、异常和常用 API。
- 支持单选、多选、概念题、代码执行结果题、选正确/选错误题。
- 支持按大纲顺序练习、大纲内随机、全范围随机、正式模拟考试。
- 模拟考试：80 题 / 180 分钟。
- 自动判分。
- 中文 / 日文切换。
- Java 关键字中日查询。
- 每题带讲解和知识点。
- 每轮按总分、大纲、题型、知识点标签统计。
- 累计作答记录本地保存，用于弱项分析。

## 架构

```text
app/src/main/java/com/vioverlord/java17trainer
├── domain   # 题目、阶段、关键字、成绩模型
├── data     # 题库生成与读取边界
├── engine   # 抽题、判分、统计、成绩存储
└── MainActivity.java # Android 原生界面
```

这版先做成可构建、可展示、可继续扩充的 MVP。后续可以把 `QuestionBank` 替换成 JSON、SQLite、Room、远程题库，UI 和判分引擎不用重写。
